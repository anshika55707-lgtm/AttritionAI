Understanding Employee Attrition Through Machine Learning

AttritionAI is a Flask-based machine learning web application that estimates employee attrition risk from selected employee details. It brings together an interactive dashboard, employee analytics and a prediction interface to demonstrate how data can support workforce analysis.

Employee Analytics Predictive Modeling Flask Web Application

Project Overview

◎

Project Objective

The objective is to explore employee data and estimate whether an employee may leave an organization. The project demonstrates how machine learning can be used to study attrition patterns and support workforce analysis.

◈

Machine Learning Model

The application loads a previously trained classification model from the models folder. The model processes the employee inputs and returns a predicted class and an estimated attrition probability.

▤

Key Features

  • Dashboard with employee summary statistics
  • Department and employee attrition analysis
  • Employee risk prediction form
  • Prediction result and probability display
  • Project overview and responsible-use information
⌘

Model Evaluation

Model performance can be assessed using Accuracy, Precision, Recall, F1-score and ROC-AUC. These metrics provide different perspectives on classification quality and are useful when evaluating attrition predictions.

How the Application Works

01

Enter Details

The user submits selected employee details through the form.

02

Process Inputs

Flask organizes the submitted information for the model.

03

Predict Risk

The saved classification model generates its prediction.

04

View Results

The result page displays the predicted class and probability.

ⓘ

Responsible Use of Predictions

An estimated attrition probability is not a guarantee that an employee will leave. Predictions depend on the training data, model quality and the details supplied. This project is intended for educational and analytical purposes; predictions should not be used as the sole basis for employment decisions.
